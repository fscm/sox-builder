# DEPENDENCIES.txt - dependency map for the SoX static build
# =============================================================================
# This file is READ BY THE MAKEFILE: it is the single source of truth for build
# ordering. Edit it whenever a dependency is added, removed or re-wired.
#
# Format (one entry per line):
#       <package>: <space-separated list of direct dependencies>
#   - A package with no dependencies is written as "<package>:".
#   - '#' starts a comment; blank lines are ignored.
#   - Names must match the package names used by the Makefile
#     (TOOLS and PACKAGES lists, plus "sox").
#
# Two groups exist:
#   TOOLCHAIN  - native build tools installed into $(TOOLCHAIN_DIR); built once.
#   LIBRARIES  - static libraries, built once PER ARCHITECTURE into
#                $(DEPS_DIR)/<arch>. Every library build implicitly requires the
#                complete toolchain (pkgconf for discovery, automake for fresh
#                config.sub/config.guess), so that is not repeated below.
#
# Rule of thumb when updating: if you bump package X, everything that lists X
# on its right-hand side must be rebuilt. The Makefile does that automatically
# on the next "make" (stamps are compared by timestamp).
# =============================================================================
